Agent Mailbox Access Protocol

Let agents take part in email, with trusted controls.

Every enterprise, of any size, runs on email. AMAP is an open specification that lets an agent read, draft and ask to send, while the credentials, the sending identity and the decision about who receives anything stay outside the agent.

How it works Read the specification

What AMAP gives you

Containment, not trust

Assume the agent will sometimes be fooled. It holds no mail credentials and can't choose its sending identity. Its only outbound act is a request.

A person on a policy miss

The runtime checks every recipient against your policy. When a request falls outside it, a person decides. Nothing is sent or dropped silently.

One side can start today

AMAP adds nothing to the mail between organisations. Your counterparties keep using email exactly as they do now.

Open and checkable

An open specification with public conformance fixtures, so anyone can test any implementation against the same rules.

Getting started

  1. Understand the model. Read how it works: three zones, a sandboxed agent, and a trusted runtime that decides.
  2. Check documents against the specification. Try the in-browser validator, or run the conformance gate yourself with python3 fixtures/validate.py from the amap-spec repository. It uses only the standard library, needs no network, and runs 89 fixtures.
  3. Run the reference implementations. Start with the reference runtime, amap-router-local, and the Claude Code connector, amap-connector-claude.

Status The AMAP specification is at v3.1.0 (draft). The AMAP Internet-Draft is ready for submission to the IETF and has not yet been submitted. There is no deployment across independent organisations yet, and we're looking for development and interop partners. Full status

Who is behind AMAP

AMAP was originated by Proofpoint and is published as an open specification under the Apache License 2.0. The specification, its schemas and fixtures, and the reference implementations are public. No one needs a particular vendor's runtime to conform or to interoperate. Get involved
