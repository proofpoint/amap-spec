The specification repository, its JSON Schemas and conformance fixtures, and the reference implementations are published under the Apache License, Version 2.0. Each repository carries its own LICENSE file, which is the authoritative grant for that repository:

  • amap-spec: the specification, schemas, fixtures and this site
  • amap-router-local: the reference runtime
  • amap-connector-claude: the Claude Code connector
  • amap-connector-codex: the Codex connector
  • amap-deploy-sandy: a working single-host deployment
  • amap-release: release manifests
